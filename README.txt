# AI-Based Cyberbullying and Online Spam Detection System

## Requirements
- Python 3.10 or newer
- Flask

## Run on Windows
1. Open CMD in this folder.
2. Install Flask:
   pip install -r requirements.txt
3. Start the website:
   python app.py
4. Open this address in Chrome:
   http://127.0.0.1:5000

## Important
This is a ready-to-run college-project demo. The detector currently uses a simple rule-based classifier, not a trained machine-learning model. For a more advanced project, the rule-based function can be replaced with a trained NLP/ML model.
